Each collector subdirectory ships its own `requirements.txt` and `README.md`; run collection via `python scripts/data_collector/<source>/collector.py download_data --region <CN|US|BR|IN> --interval 1d|1min ...`. Download prebuilt datasets with `python scripts/get_data.py qlib_data --target_dir ~/.qlib/qlib_data/<region>_data --region <cn|us> [--interval 1min]`. Convert normalized CSVs to Qlib bin with `python scripts/dump_bin.py dump_all|dump_fix|dump_update --data_path <normalize_dir> --qlib_dir <qlib_dir> --freq day|1min`. PIT statement dumping uses `python scripts/dump_pit.py`. Data health checks are invoked via `python scripts/check_data_health.py check_data --csv_path ...` or `--qlib_dir ...`.
