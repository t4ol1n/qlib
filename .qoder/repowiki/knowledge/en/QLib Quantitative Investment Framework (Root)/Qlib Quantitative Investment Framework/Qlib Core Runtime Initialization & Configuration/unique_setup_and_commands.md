`qlib.init()` must be called before using any data/workflow component; it supports three entry points — `qlib.init(default_conf='client'|'server', **kwargs)`, `qlib.init_from_yaml_conf(path)`, and `qlib.auto_init()` which walks up the filesystem looking for a `config.yaml` and supports `conf_type: origin|ref` merging. When `provider_uri` uses an NFS path, `auto_mount=True` triggers automatic `mount.nfs` execution (Linux/macOS) or `mount -o anon` (Windows); otherwise the path must exist or be mounted externally.
