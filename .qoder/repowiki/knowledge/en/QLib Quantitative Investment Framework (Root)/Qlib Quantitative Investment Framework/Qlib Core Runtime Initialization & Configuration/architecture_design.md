This leaf module is the entry point of the `qlib` package and defines the bootstrapping layer that every other subsystem depends on. `qlib/__init__.py` exposes `init()`, `init_from_yaml_conf()`, `auto_init()`, and `get_project_path()` as the public API; `init()` lazily imports `config.C` and `data.cache.H`, applies mode-specific defaults via `C.set(default_conf)`, mounts NFS provider URIs through `_mount_nfs_uri`, and finally calls `C.register()` to wire up operators, wrappers, and the experiment recorder. `config.py` defines a layered config system: a Pydantic `BaseSettings` (`QSettings`) reads env vars under the `QLIB_` prefix with nested delimiter support; a generic `Config` dict wrapper holds the mutable runtime state; `QlibConfig` extends it with mode templates (`MODE_CONF['client'|'server']`), region presets (`_default_region_config`), a nested `DataPathManager` that resolves local vs NFS URIs into mount paths, and a `register()` method that dynamically imports and initializes downstream subsystems (ops, wrappers, workflow). `constant.py` centralizes cross-cutting literals such as region codes (`REG_CN/US/TW`), numeric epsilons, and pandas time deltas. `log.py` implements a module-aware logger factory (`get_module_logger`) backed by a `QlibLogger` metaclass proxy and a `_QLibLoggerManager` singleton that caches per-module loggers and auto-prefixed names under `qlib.*`; it also provides a `TimeInspector` timer context manager and a `LogFilter` for regex-based message filtering. `typehint.py` re-exports version-compatible `Literal`, `TypedDict`, `final` and defines the `InstConf` / `InstDictConf` TypedDict used throughout Qlib to describe class instantiation from configuration dicts. Dependency direction is strictly outward-only: this module has no qlib subpackage imports except inside functions (lazy imports in `init`, `set`, `register`) to avoid circular imports, while all other qlib modules import from here for configuration and logging.
