The root acts as the distribution and development entry point for the `qlib` Python package (`pyqlib`). It wires together five child scopes — the core library (`qlib_core`), data collection scripts (`scripts`), runnable examples (`examples`), Sphinx documentation (`docs`), and pytest suite (`tests`) — through a single `pyproject.toml`/`setup.py` manifest. The package is built with setuptools + setuptools-scm, exposing the `qrun` CLI via `[project.scripts]`, and ships two Cython C++ extensions (`qlib.data._libs.rolling`, `qlib.data._libs.expanding`) compiled in-place by the `Makefile prerequisite` target. Optional dependency groups (`rl`, `dev`, `lint`, `docs`, `test`, `analysis`, `client`, `package`) let each child scope install only what it needs. CI/release automation lives under `.github/workflows` and `.github/release-drafter.yml`, while pre-commit hooks (`.pre-commit-config.yaml`) enforce Black/Pylint/Flake8/Mypy across all children uniformly.
