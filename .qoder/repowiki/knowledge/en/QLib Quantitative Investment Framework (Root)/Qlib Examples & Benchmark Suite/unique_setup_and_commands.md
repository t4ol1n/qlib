Run a single workflow via `qrun examples/benchmarks/<Model>/workflow_config_<model>_<dataset>.yaml`. Run all benchmarks across multiple seeds with `python examples/run_all_model.py run <times> [models] [Alpha158|Alpha360] [csi300|csi500]`, which provisions per-model conda envs, installs requirements, and writes aggregated results to `table.md` under an experiment folder. High-freq example uses `python examples/highfreq/workflow.py get_data` after downloading 1min data via `GetData().qlib_data(..., interval='1min')`.
