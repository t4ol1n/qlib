Built with Sphinx using `conf.py` as the central configuration (theme `sphinx_rtd_theme`, extensions `autodoc`, `napoleon`, `mathjax`, `todo`). The entry point `index.rst` defines the top-level table of contents grouped into six sections: GETTING STARTED, FIRST STEPS, MAIN COMPONENTS, OTHER COMPONENTS/TOPICS, FOR DEVELOPERS, REFERENCE, plus FAQ and Change Log. Content is split by audience/topic into subdirectories (`introduction/`, `start/`, `component/`, `advanced/`, `developer/`, `hidden/`, `reference/`, `FAQ/`, `changelog/`) and linked via RST `toctree` directives; the `hidden/` directory is excluded from builds via `exclude_patterns`. Static assets (logos, diagrams, QR codes) live under `_static/img/`. API docs are generated from Python source through autodoc driven by `reference/api.rst`. Build targets are exposed via `Makefile`/`make.bat`, which install dependencies from `requirements.txt` before invoking `python3 -msphinx`.
